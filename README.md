- **Responsive Design** - Works on desktop, tablet, and mobile

---

## How to Use This Code

### **View it live:**

Visit [vnunhardtova.cz](https://vnunhardtova.cz)

### **Run it locally with Jekyll:**

1. Install Ruby and Bundler
2. Run `bundle install`
3. Run `bundle exec jekyll serve`
4. Open `http://localhost:4000`

### **Add a new blog post easily:**

Create a file in `_posts/` with a name like `2026-08-14-my-post.md` and include front matter like:

```yaml
---
title: "Your first post"
category: "Blog"
accent: "linear-gradient(135deg, #8b5cf6 0%, #c084fc 100%)"
excerpt: "Short text as example"
---

Full text.
```

Then the post will appear automatically on the blog page.

### **Modify for your own use:**

**To customize this for yourself:**

1. Edit `data/links.js` - Add your social media links
2. Edit `data/bio.js` - Write your own bio and CV
3. Edit `data/gallery.js` - Add your portfolio images
4. Edit `index.html` - Change name, bio, and profile info
5. Edit `style.css` (variables at top) - Change colors
